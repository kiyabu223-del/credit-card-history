# クレジットカード利用履歴 — 1枚撮影モード

レシート全体を1枚撮影し、日付・利用店・合計金額を読み取ります。
店名まで鮮明に写るように撮影し、結果は保存前に確認・修正してください。

## 読み取り
- 全体写真から日付・店名・合計金額を抽出します。
- 明るい紙の領域を検出できる写真では、レシート左右の背景を除いてから読み取ります。検出できなければ元の横幅を使います。
- 合計ラベルが見つからない場合は、高解像度・疎な文字配置モードで位置を再確認します。
- 合計ラベル直後から金額行を切り出します。読み取れた数字の位置で左端を切らないため、先頭桁も読み取り範囲に含まれます。金額が直下の行にある配置にも対応します。
- 金額部分は数字の高さに合わせて上下の行や罫線を避け、右側の背景も除いて切り出します。最大幅3600px・最大4倍で拡大し、余白を追加します。
- 写真の明るさ分布から白黒変換のしきい値を自動計算します。異なる2つのしきい値で、英語モデル・数字専用・1行認識モードのOCRを行います。
- 千区切り後の広い空白や、円記号をバックスラッシュと誤認した数字にも対応します。
- 2回の金額が一致すれば採用します。結果が食い違う場合は金額を空欄にし、確認を促します。一致していてもOCRの正確性は保証されないため、写真と照合してください。
- OCR設定はworker.setParametersで適用します。再読み取りに失敗した場合は全体写真の結果を表示し、確認を促します。
- 合計の位置を特定できず再読み取りに進めない場合も、全体OCRで抽出した金額候補を表示し、写真との確認を促します。候補がなければ空欄になります。
- 「総額」「お買上金額」「お支払い金額」「TOTAL」「AMOUNT DUE」などの表記と、「合計¥1,234」のようにラベルと金額が一つのOCR単語になった形式に対応します。
- 同じ元写真の上部40％を切り出して店名を再読み取りします。追加撮影は不要です。
- 店名部分は最大幅2400px、最大2倍に拡大し、グレー化とコントラスト補正を行います。
- 大きな文字、店名辞書、近接する店名・支店名の複数行、既存の店名学習を使います。
- 再読み取りの失敗や候補がない場合は、全体写真の店名を使います。
- 日付を抽出できない場合は今日の日付を入れます。
- 拡大によって、元画像で失われた文字情報は復元できません。

## 利用履歴
- 月別一覧・合計・件数表示、手動入力、編集、確認付き削除。
- 履歴と店名学習はブラウザ内に保存します。写真は保存しません。
- 外部からOCR関連ファイルを読み込むため、オフラインでのOCRは保証されません。

## 更新
GitHub Pagesへ反映する際は、index.htmlとsw.jsを含む更新ファイルを配置してください。
今後のコード修正時は、画面タイトル横の修正日時も日本時間で更新してください。表示形式は `2026/10/4 13:24` です。閲覧時刻ではなく、コードの修正日時を固定で表示します。

## 処理のテスト
`node ocr.test.cjs`で設定適用、金額候補、入力欄への反映、結果不一致の処理を確認できます。OCR自体はモックであり、実画像での精度を測るテストではありません。

2026/10/4の修正では、提供された大戸屋のレシート写真をChromeとTesseract.js 5.1.1で実OCR検証し、2回の金額OCRがそれぞれ4,620円を返し、画面の金額欄に4620が入ることを確認しました。他の実写真での精度は別途確認が必要です。
