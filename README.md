# クレジットカード利用履歴 v2.4

今回の重点修正

## 合計金額
- 「合計」「総合計」「お支払額」「ご請求額」などの行を最優先
- 合計ラベルの右側の数字を最優先
- 合計の直下1〜2行も候補
- 数字そのものの文字高さを、レシート内の標準文字サイズと比較
- 他より大きい数字を加点
- 行全体が大きい場合も加点
- 右端寄せの数字を加点
- 同じ金額が「合計」「カード支払」など複数回出る場合を加点
- 小計・税・釣銭・預り金・ポイント・値引を除外

## 店名学習
- 以前はOCRで選ばれた1行だけを学習していたため、OCRの揺れで一致しにくい問題がありました
- v2.4ではレシート上部の上位3候補をまとめて特徴化
- 2文字単位の特徴で比較するため、多少の誤認識・欠けでも過去の修正店名に一致しやすくしました
- 修正した店名はSafari内に最大100件保存します
