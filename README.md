# クレジットカード利用履歴 v3.0

継ぎ足しではなくOCR部分を全面的に作り直した版です。

## 設計
- OCRは原則1回だけ実行
- 1回のOCRから取得した文字位置と文字サイズを使って店名・合計を判定
- 日付は全文テキストから抽出
- 店名はレシート上部38%以内の大きい文字を優先
- 電話、住所、日時、合計、小計などを店名候補から除外
- 店名を手で直して保存すると、上部候補3行の特徴を学習
- 合計は「合計」「お支払額」「請求額」等の行を最優先
- 合計行の右側の数字を最優先
- 直下1〜2行も候補
- 他より大きい数字、右寄せ数字を加点
- 1 , 234 / 1 234 / 1, 234 のような分割金額を再結合
- 同じ金額が複数回出る場合を加点
- 小計、税、釣銭、預り、ポイント、値引を除外
