# クレジットカード利用履歴 v2.5

今回の修正は「1,234円」の4桁目が消える問題への対策です。

## 金額OCR改善
- OCRが `1` `,` `234` の3つに分けても、同じ行で近接していれば `1,234` と再結合
- OCRがコンマを読めず `1` `234` と分けても、横の間隔が狭ければ `1234` と復元
- コンマが「，」「・」「.」などに誤認識された場合も補正
- 結合して4桁以上の金額になった候補を強く加点
- 「合計」の右側にある結合済み金額を最優先
- 文字サイズ、右寄せ、合計行、重複金額のスコアリングも継続

GitHub Pagesでは index.html と sw.js の2ファイルを上書きしてください。
