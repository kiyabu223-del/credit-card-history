# クレジットカード利用履歴 v2.2

今回のOCR改善
- OCRを3回に分ける方式へ変更
  1. 全体：日付
  2. 上部35%：店名
  3. 下部55%：合計金額
- 「合計」「総合計」「お支払額」「ご請求額」等を位置情報付きOCRで検出
- 「合計」の右側にある金額を最優先
- 合計と金額が改行されている場合は直下1〜2行を探索
- 小計・消費税・釣銭・預り金を除外
- 店名はレシート上部の「大きめの文字」「高信頼度」「住所・電話以外」を優先
- 位置情報が取れない環境では従来のテキスト判定へ自動フォールバック
- 保存機能はv2.1の修正を継続
