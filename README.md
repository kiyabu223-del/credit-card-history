# クレジットカード利用履歴 — Webアプリ版

MacなしでiPhoneのSafariから使えるようにした試作版です。

## できること
- レシートをカメラ撮影 / 写真から選択
- OCRで文字認識
- 日付・利用店・金額を自動抽出
- OCR結果を保存前に手動修正
- 月別一覧
- 月ごとの利用合計
- 手動入力
- 編集・削除
- ブラウザ内（localStorage）に保存
- ホーム画面に追加してアプリ風に使用

## 大事な点
OCRには Tesseract.js を利用しています。
初回OCR時にはインターネット接続が必要です。

## iPhoneで使う方法
このフォルダをそのままWebサーバーに公開してください。
PWA（ホーム画面追加）やカメラ利用を安定して使うには HTTPS が必要です。

無料公開先の例：
- GitHub Pages
- Netlify
- Cloudflare Pages

公開後、iPhoneのSafariでURLを開き、
共有ボタン → 「ホーム画面に追加」
でアプリのように使えます。

## データ保存について
利用履歴はSafariの localStorage に保存されます。
SafariのWebサイトデータを削除すると履歴も消える可能性があります。
重要なデータの長期保存用途では、将来CSV書き出しやクラウド保存機能を追加することを推奨します。

## ファイル
- index.html : アプリ本体
- manifest.webmanifest : PWA設定
- sw.js : オフライン用サービスワーカー
- icon.svg : ホーム画面用アイコン
