# クレジットカード利用履歴 v2.3

店名認識を重点改善した版です。

- レシート上部の候補を、位置・文字サイズ・OCR信頼度で再評価
- よくある店舗チェーン名を日本語/英語表記から補正
- OCRの軽い崩れを近似文字列比較で補正
- OCR後に店名を手で直して保存すると、その読み取り特徴と正しい店名をiPhone内に学習
- 次回似たOCR結果が出た場合、学習済み店名を優先
- 学習データはSafari内だけに保存し、外部には送信しません
- v2.2の合計金額の位置情報読み取りも継続

GitHub Pagesでは index.html と sw.js の2ファイルを上書きしてください。
