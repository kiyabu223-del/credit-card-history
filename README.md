# クレジットカード利用履歴 v3.1 — 3枚撮影モード

小さい文字対策として、レシートを3枚に分けて撮影してOCRする版です。

## 撮影
1. レシート全体
   - 日付と全体構造
2. 店名をアップ
   - 店名が画面いっぱいになるくらい寄って撮影
3. 合計をアップ
   - 「合計」と金額が一緒に入るように撮影

## 読み取り
- 全体画像 → 日付
- 店名アップ → 店名専用OCR
- 合計アップ → 合計専用OCR
- 合計アップで失敗した場合は全体画像へフォールバック
- 店名アップで失敗した場合も全体画像へフォールバック

## 継続している機能
- 店名学習
- レシート上部の大きい文字を優先
- 「合計」行・右側・大きい数字・右寄せを優先
- 1 , 234 / 1 234 / 1, 234 の再結合
- 小計、税、釣銭、預り、ポイント、値引を除外
- 月別一覧・合計・編集・削除
